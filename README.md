## FAQ

**Can I choose the cat's appearance?**  
Yes — open Settings and pick from 20+ coat patterns including tabby, calico, black, white, and custom colors.

**Will it slow down my PC?**  
No — the cat uses sprite animations (not 3D) and sits under 30MB RAM. Invisible performance impact.
